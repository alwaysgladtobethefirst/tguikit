# Security policy

## Reporting a vulnerability

Report privately through GitHub's [security advisories](https://github.com/alwaysgladtobethefirst/tguikit/security/advisories/new). Please don't open a public issue for a security problem.

You'll get an acknowledgement within a few days and a fix or a timeline once it's confirmed.

## Supported versions

Only the latest `0.x` release receives fixes while the package is pre-1.0.
